# CLAUDE.md

## Repository Overview

This is a **GitHub profile repository** (`agi22024/agi22024`). It is a special GitHub repository whose `README.md` is displayed on the owner's GitHub profile page at `https://github.com/agi22024`.

This is not a software project — it contains no application code, build system, tests, or dependencies.

## Repository Structure

```
.
├── CLAUDE.md    # This file — guidance for AI assistants
└── README.md    # GitHub profile content (displayed on the user's profile page)
```

## Key Files

- **README.md** — The sole content file. Its contents render directly on the GitHub profile. Currently contains the default GitHub template with placeholder sections (working on, learning, collaborating, etc.). Edits to this file change what visitors see on the profile.

## Development Workflow

- **No build step** — Changes to README.md take effect immediately once pushed to the default branch (`master`).
- **No tests** — There is no test suite to run.
- **No linting** — There is no linting or formatting configuration.
- **No CI/CD** — There are no GitHub Actions or other CI pipelines.
- **No dependencies** — There is no package manager or dependency file.

## Conventions

- The repository uses `master` as its default branch.
- Commits are GPG-signed using SSH format.
- README.md uses GitHub-Flavored Markdown, which supports HTML, images, badges, and other GitHub-specific features (profile stats widgets, streak counters, etc.).

## Working with This Repository

When making changes:

1. Edit `README.md` to update the profile content.
2. Use valid GitHub-Flavored Markdown (GFM). HTML is also supported.
3. Commit with a clear message describing what changed on the profile.
4. Push to `master` to publish changes live on the GitHub profile.
